# Semaphore-Chataigne-Module

A Châtaigne module to interact with [Semaphore](https://semaphoreui.com/), a web front-end for [Ansible](https://www.redhat.com/en/ansible-collaborative).

## Usage
Authentication is done via an API token, which can be issued from the Semaphore admin interface. Paste that token in the _Token_ field of the module and have fun.

## Features
This module allows you to
- [Start a task](https://semaphoreui.com/api-docs/#/task/post_project__project_id__tasks)
